## Execution Guidelines

To implement any plan:
1. Provide the respective `.md` file to your coding agent or run `improve-animations execute <plan-path>`.
2. Review the resulting diff against the verification checks specified in each plan.
3. Run `tsc --noEmit` and verify responsive viewports across standard and reduced-motion states.
